8. Export Workflow
   STATUS: PARTIAL PASS — BUG FOUND (FIX-2)

Validated:

* Export button
* Export API endpoint (202 queued response, format=pdf confirmed)
* Celery export job creation
* Task dispatched successfully

Issue:
Celery worker crashes during export execution on Windows.

Root Cause (confirmed):
Windows Python 3.8+ defaults to ProactorEventLoop.
asyncpg requires SelectorEventLoop.
Worker calls asyncio.run() with no loop policy override.
Connection attempt fails before DB session opens.
Error: AttributeError: 'NoneType' object has no attribute 'send'

Impact:
Status reset in except block also fails (same DB connection issue).
Export job stuck in RUNNING / never completes.

Fix:
Add WindowsSelectorEventLoopPolicy before asyncio.run() in:
  backend/app/workers/heavy/syllabus_export.py
  backend/app/workers/heavy/syllabus_generation.py

10. References Search
    STATUS: FAIL — BUG FOUND (FIX-1)

Issue:
References search endpoint returns 422 VALIDATION_ERROR.

Root Cause (confirmed):
Frontend ReferenceSearchRequest type (frontend/src/types/syllabus.ts:322)
uses field name `query`.
Frontend passes { params: request } to axios, sending ?query=...
Backend router.py:695 declares: q: str = Query(...) — expects ?q=...
Parameter name mismatch → FastAPI returns 422 missing required field q.

Affected files:
  frontend/src/lib/api/syllabuses.ts:264-266
  frontend/src/types/syllabus.ts:322 (type field name)
  backend/app/modules/m02_syllabus/router.py:695 (source of truth)

Fix:
Map query → q when building axios params in searchReferences().
Type definition kept as-is (frontend naming stays readable).
One-line change in api/syllabuses.ts.

          instead of passing the full request object as params.

  Files:
    backend/app/workers/heavy/syllabus_export.py
    backend/app/workers/heavy/syllabus_generation.py
  Change: Added `import sys` and `if sys.platform == "win32":
          asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())`
          before asyncio.run() in each task function.
  Result: Workers use SelectorEventLoop on Windows; asyncpg connects correctly.
          Status-reset path in _run_generation except block now works on Windows.
  Verified: Both workers import cleanly; task names confirmed.
